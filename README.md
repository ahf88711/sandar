# سندار — عهد القيادة

لعبة استراتيجية عربية لإدارة دولة نامية وتحويلها إلى أمة وازنة عبر قرارات اقتصادية وطاقية وصناعية وتقنية ودفاعية مترابطة.

## التشغيل المحلي

```bash
npm install
npm test
npm run dev
```

البناء للإنتاج:

```bash
npm run build
npm run preview
```

الحفظ يتم محلياً في المتصفح. الواجهة بالكامل بالعربية ومن اليمين إلى اليسار.
